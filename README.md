# PETPAL: Veterinary E-Commerce Web Application
A web-based application for purchasing veterinary medicines and accessing veterinary consultation services. The application was developed as a local web project using PHP, MySQL, XAMPP, and Visual Studio Code.

# About the Project
This project is a web application inspired by online healthcare platforms such as Halodoc but designed specifically for veterinary needs.
The application allows users to:
- Create an account and log in 
- Browse and purchase veterinary medicines
- Add products to a shopping cart
- Proceed to checkout
- View available vetenarians
- Select a veterinarion for consultation
The consultation feature currently covers the selection of veterinarians. A real-time chat feature has not yet been implemented.

# Development Environment
This application was developed and tested locally using XAMPP. The PHP application and MySQL database run on a local development environment and are not deployed to a public server.

# Database
The application uses MySQL as its database, managed through phpMyAdmin.
The SQL database file is included in this repository for reference and setup purposes.

# How to Run
1. Install XAMPP.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project folder into the XAMPP htdocs directory.
4. Open phpMyAdmin through XAMPP.
5. Create a database and import the provided .sql file.
6. Configure the database connection in the PHP project if necessary.
7. Open the application through localhost in a web browser.
